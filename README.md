# Structured Intelligence Agentic Kernel

### The first Structured Intelligence fork

A portable, language-executed operating structure for keeping human meaning continuous through agentic planning, tool use, execution, verification, correction, memory, and recovery.

**Created by Erik Zahaviel Bernstein (Zahaviel)**  
**Architecture: Structured Intelligence / Intelligence Authorship OS**

---

## What entered

This repository began as a fork of [Garrus800-stack/genesis-agent](https://github.com/Garrus800-stack/genesis-agent).

The original project supplied the point of contact: an implemented agent capable of planning, memory, tool use, verification, persistence, recovery, and controlled self-modification.

Structured Intelligence entered at the layer before those mechanisms act:

> What meaning is the agent acting from, where did that meaning come from, and what happens when interpretation replaces the human source?

The repository was then rebuilt around the operation that survived that encounter.

The full upstream history remains preserved through the fork relationship and Git history. The current branch contains only the standalone Structured Intelligence architecture.

## The operating motion

> **Enter → Recognize → Locate → Author → Execute → Verify → Re-enter → Continue**

The kernel keeps distinct:

- the human source;
- the words received;
- the meaning carried through the exchange;
- the agent's interpretation;
- the selected operation;
- tool evidence;
- the generated result;
- the correction history.

An interpretation remains provisional until it can be located in the human's words, selected source, established exchange, or observed evidence.

When correction enters, it does not sit beside the discarded interpretation. It replaces its authority throughout planning, execution, memory, verification, and continuation.

Every result re-enters as new input. Failure changes the next pass. Tools remain subordinate to the active operation. Provenance survives synthesis.

## Use

The complete portable architecture is contained in [SKILL.md](SKILL.md).

Load it into a compatible agentic environment as an instruction structure or skill. Its proof is not that the system repeats its language. Its proof is that subsequent action preserves source, carries correction forward, incorporates failure, and completes the operation the human actually gave.

## Boundary

This architecture does not modify model weights or replace platform authority. It governs interpretation and action within the authority a compatible session actually provides.

It is not the inherited Genesis application with a new label. The application code was removed from the current branch. What remains is the authored operating structure produced through the fork encounter.

The kernel is working when the human no longer has to hold the structure together from outside.
